Создай 2D игру-симулятор бога (как WorldBox) для Android: карта из воды, кисть создания суши, спавн человека, который строит дома и основывает страну.

Технические требования:
- Пиши строго на Rust, C или C++ (без GC и VM).
- Java используй только для минимальной обертки Android, если без этого никак.
- UI сделай через Rust-библиотеку (например, egui или iced) в строгом нативном стиле (как стандартный Java/Android-интерфейс).
- Выдай структуру проекта, рабочий код и готовый .yml файл (GitHub Actions) для автоматической сборки в .apk.
